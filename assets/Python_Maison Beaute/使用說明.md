# Maison Beauté 專案：Python 操作步驟

資料集：Kaggle「Customer Personality Analysis」（Patel, 2021），2,240 筆客戶資料，欄位用 Tab 分隔。

## 1. 安裝套件（只需一次）

```
pip install -r requirements.txt
```

## 2. 依序執行三個腳本

```
python 01_cleaning.py
python 02_key_figures.py
python 03_charts.py
```

| 腳本 | 做什麼 | 產出 |
|---|---|---|
| `01_cleaning.py` | 移除重複客戶、補缺失收入（中位數）、標記極端收入和不合理出生年份、整理婚姻狀態 | `data/clean/`、`reports/` |
| `02_key_figures.py` | 用原本的方法和清理後的資料各算一次所有數字，並和網站比對 | `results/key_figures_V{n}.csv` |
| `03_charts.py` | 畫 4 張圖，法文和英文各一套，用專案自己的美妝配色（瓷白底、梅紫、玫瑰粉、玫瑰金、薰衣草紫），標題用 Playfair Display | `charts/V{n}/` |

每次執行都會產生新的版本號（V1、V2…），不會覆蓋舊檔。
