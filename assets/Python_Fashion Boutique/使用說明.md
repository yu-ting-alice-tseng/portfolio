# 時尚精品店專案：Python 操作步驟

資料集：Kaggle「Retail Fashion Boutique Data Sales Analytics 2025」（Puri, 2025，合成資料，2,176 筆）

## 1. 安裝套件（只需一次）

在這個資料夾打開終端機（檔案總管網址列輸入 `cmd` 後按 Enter），執行：

```
pip install -r requirements.txt
```

## 2. 依序執行三個腳本

```
python 01_cleaning.py
python 02_key_figures.py
python 03_charts.py
```

| 腳本 | 做什麼 | 產出 |
|---|---|---|
| `01_cleaning.py` | 檢查重複、缺失值、價格一致性、異常值，加上標記欄位（不刪任何一筆） | `data/clean/` 清理後資料、`reports/` 清理報告 |
| `02_key_figures.py` | 從清理後資料重算網站上的所有數字，並和網站上的數字比對 | `results/key_figures_V{n}.csv`（`match` 欄出現 `NO` 就要檢查網站） |
| `03_charts.py` | 畫 4 張圖，法文和英文各一套，用專案自己的時尚配色（象牙白底、每張圖一種布料色：酒紅、海軍藍、粉玫瑰、駝色、鼠尾草綠），標題用 Bodoni Moda | `charts/V{n}/` |

每次執行都會產生新的版本號（V1、V2…），不會覆蓋舊檔。

## 3. 清理發現（V1）

- 沒有重複資料，價格計算全部一致。
- 尺寸缺 491 筆：402 筆是配件（本來就沒有尺寸），89 筆是衣服或鞋子真的缺。
- 評分缺 362 筆（16.6%），平均分只算有評分的商品。
- 鞋子的尺寸是 XS 到 XXL（衣服尺寸），不合理，所以不分析尺寸。
- **購買日期**：1,641 筆（75.4%）都在 06/08/2025，也就是資料的最後一天，其他每天只有 1 到 6 筆。這很可能是預設值，所以不做時間趨勢或季節性分析。
- 各品類、品牌、顏色、季節的數量幾乎一樣，折扣和評分也平均分佈：符合 Kaggle 說的合成資料。

網站上的 40 個數字全部重算吻合，清理後不需要改。
